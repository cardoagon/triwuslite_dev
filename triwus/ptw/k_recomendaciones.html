Recomendaciones para la elección de contraseñas

Los siguientes consejos serán útiles para la elección de una buena contraseña:

  1. No usar contraseñas que sean palabras o nombres propios.
  2. No usar claves numéricas con algún significado: teléfono, NIF, fechas de nacimiento, ...
  3. Elegir una contraseña que mezcle caracteres alfabéticos, numéricos y signos de puntuación.
  4. La longitud recomendable es de 8 caracteres o más.
  5. No usar la misma contraseña para todo. Es posible crear una contraseña a partir de variaciones de otra anterior.
  6. Una contraseña debe ser fácil de memorizar para no tener que escribirla. A continuación se exponen varias técnicas que permiten generar contraseñas seguras y fáciles de memorizar:
    • Combinar palabras cortas con algún número o carácter de puntuación
      abril2002
    • Usar un acrónimo que sea fácil de recordar
      A río revuelto ganancia de pescadores → Arrgdp
    • Añadir y/o reemplazar letras por signos o números
      abril2002 → 4bril,20.S
      Arrgdp → Ar_r9dP

Recomendaciones para proteger tu contraseña

  Una contraseña debe ser como un cepillo de dientes: usar a diario, cámbialo regularmente, y no se comparte con nadie. Para proteger su contraseña debe seguir los siguientes consejos:

  1. Nunca se debe compartir con nadie. En caso de que fuera necesario, cámbiala inmediatamente.
  2. No escribir la contraseña.
  3. No teclear la contraseña si está alguien mirando. Recíprocamente, no debemos mirar cuando alguien teclea su contraseña.
  4. No enviar la contraseña por correo electrónico, ni mencionarla en una conversación.
  5. No mantener una contraseña indefinidamente. Cámbiala regularmente.
